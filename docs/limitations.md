# Limitations

| # | Limitation | Impact | Status |
|---|---|---|---|
| L1 | **Customer-level leakage across the time split.** 3,864 customers have 2–3 loans (3,043 with 2, 821 with 3). A customer's loans can originate on different dates, so one loan can land in train and another in test, and both share identical `bur_*` (and `bur_pit_*`) customer-level features. | May inflate test AUC, since the model has seen that customer's bureau profile during training. | A grouped split (by customer_id) was considered and deferred: it would shrink the test set and complicate the time-based framing the stack calls for (A2/A3 in `docs/assumptions.md`). **Measured (sub-problem 4), effect inconclusive:**<br>- 2,070 of 4,921 test accounts (42%) belong to a customer seen in training. AUC on those is 0.656 vs 0.684 for new customers (LightGBM), but these are different populations, so the comparison cannot show inflation.<br>- Grouped retrain (`src/validation.py`; 2,255 shared-customer train rows dropped, 9,764 → 7,509): test AUC 0.675 → 0.672 (LR), 0.673 → 0.658 (LightGBM). The drop cannot be separated from the 23% smaller train set.<br>- Among customers with more than one loan, the default rate is 23.3% when another of the customer's loans defaulted vs 14.6% otherwise. |
| L2 | **LightGBM does not outperform logistic regression** (test AUC 0.673 vs 0.675; bootstrap 95% CI for the difference −0.008 to +0.014, inconclusive; `src/validation.py`, *corrected* from +0.015). The first run overfit (300 trees: train AUC 0.994, test 0.633); the tree count is now set by early stopping on the 2021 in-train holdout. | LR is the champion (on par, simpler to govern); LightGBM is the challenger. | Documented in `docs/model_report.md` |
| L3 | **No formal calibration, and no LGD or recovery data.** | Brier and decile predicted-vs-observed are reported as a diagnostic only. LightGBM's scores are compressed at both ends. There is no loss-severity view. | The dashboard shows risk bands, not probabilities |
| L4 | **Bureau features are snapshots, including in the opened-before-origination variant** (A2). The target has no event date or horizon (A4). | Reported AUCs are optimistic for a real month-3 decision; the true point-in-time AUC is unknown. Swapping `bur_*` for `bur_pit_*` in the LR champion gives AUC 0.671 vs 0.675 (difference +0.005, bootstrap 95% CI −0.002 to +0.012, inconclusive); the kept lines still carry snapshot status, balance and DPD, so this does not show the champion is leakage-free. | Needs as-of-date bureau pulls and a dated default definition (see assumptions) |
| L5 | **LightGBM out-of-sample PSI baseline is approximate** — category lists come from ≤2021 rows and tree count was early-stopped on 2021; LR champion baseline is fully ≤2020. | Diagnostic only. | Documented in `docs/model_report.md` (monitoring plan) |
